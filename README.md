# STOCKRAGEPOS

Point of sale by Rhean Villa and Kurt Alonzo.

[Stockrage POS v7](stockrage-pos-v7-lightdark/stockrage-pos/README.md) is the project. Run all application commands from `stockrage-pos-v7-lightdark/stockrage-pos`. Its frontend uses Blade, Tailwind, and Alpine.js.

For the local demo, follow the v7 setup instructions with a fresh MySQL database. Seed the sample products and optionally run `php artisan db:seed --class=DemoSalesSeeder` for sales history. Run `php artisan test` and `npm run build`, then rehearse the dashboard, product setup, checkout, receipt, stock history, void, and reports in light and dark mode.
