## Reproduction and fault controls

Use `npm run test:pos-browser`. The harness confines migration/reset to `storage/framework/testing/task5-browser/test.sqlite`, file cache/session/view directories beneath that same testing directory, and a private config cache. The fixture refuses any other database/storage path. Feature tests use disposable SQLite; no development database migration was run.

The response-loss interceptor calls the actual Laravel handler through `route.fetch()` before dropping its response. The pending interceptor instead registers the original request through the real CLI worker and stops it at the durable barrier before any financial writes. Refresh must show unknown status; only explicit Resume same attempt may POST the original payload. Final state is one sale/payment and six movements. Local marker failure retains the verified sale and disables New Sale.
